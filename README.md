A fast, modern landing page for an AI development service, built with **Claude Code**. It's a single `index.html` file: no framework, no build step, free hosting on GitHub Pages.

## ✨ Features

- **Responsive:** looks great on phones, tablets and desktops
- **Fast:** one HTML file, no JavaScript framework
- **SEO-ready:** page title, meta description and clean headings
- **Modern design:** dark theme, red neon accents, hover animations, sticky navigation
- **Sections:** hero, services, process and a call to action

## 🚀 Run it yourself

1. Download `index.html`
2. Open it in any browser

To put it online for free: push it to a GitHub repo, then go to **Settings → Pages → Deploy from branch → main**.

## 🛠️ Customize

Change the text, colors (the `:root` variables at the top of the CSS) and sections to fit any business.
